## 09:30 主界面：飞机压住 UI + 左边缘按钮叠在一起 + 侧边栏点不动

**三处真因（都已定位到字段/代码行）**

1. `MainCanvas` 是 **ScreenSpaceCamera**（`m_RenderMode: 1`，planeDistance 400），
   `UIViewManager.SetLayer(key)` 直接 `canvas.sortingOrder = key` → 主界面 UI 在 **1** 层，
   而玩家飞机 `player_plane.prefab` 的 SpriteRenderer 是 **40**。
   同一条透明队列里 40 > 1 → 玩家拖动飞机时飞机会盖住整个主界面。
2. `ui_mainview.prefab` 里后加的两个按钮用的是中心锚点：
   `cebianBtn` apos(-441,120)、`jiliBtn` apos(-348.5,-11)，
   换算到 1080×2411 画布正好落在左边缘 y≈288..353px，
   压在原生的离线奖励气泡 `TranOffline/ImgOffline`（锚左上 + apos y=-1004.6，落在 y≈298..367px）上面，
   气泡的倒计时(24:00)/进度环/领取按钮被整块吃掉 → 视觉「按钮叠在一起」，点击也点不到。
3. `cebianBtn` **没挂任何脚本**，Button 的 `m_OnClick` 也是空的。按 GUID 反查
   `cebian.cs` 在 prefab/unity 里命中 0 处 → 纯装饰图，点不出侧边栏。
